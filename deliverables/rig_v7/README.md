# Приёмка rig_v7 — костюм: `transparent_s0`, боксы и ворота по коже

Первый арт второй половины покрытия. Здесь важна не столько заплата, сколько два инструмента,
которые она вытащила наружу: **как ставятся боксы лица** и **чем меряется дрейф, когда лицо
в кадре маленькое**.

## Почему ворота переехали на кожу

Боксы на костюме сначала были проставлены «по линейке» и оказались **неверны на всех четырёх
артах**: у `s1` левый бокс стоял на волосах, у `s2`/`s3` рот был сдвинут на 40–50 px. Первый же
признак — кроп для генерации, в котором виден один глаз вместо двух.

Замер теперь: кроп области лица в 5–8× с сеткой каждые 10 px и подписями каждые 50 px, координаты
читаются по ней, затем проверяются рамками поверх **того кропа, который пойдёт в генерацию**.

Про метрику: на мелком лице полоса вокруг глаз ложится в основном на пряди, и цифры перестают
упорядочивать —

| случай | по полосе | по коже |
|---|---|---|
| `t4_s0`, патч в порядке | **125.2** | 5.3 |
| `transparent_s0`, аккуратные веки | 11.7 | **10.4** |
| `transparent_s0`, та же модель, но перерисовала всё лицо | 23.1 | 22.5 |
| `transparent_s2`, перерисовка целиком | 41.0 | 45.8 |

Поэтому ворота — дрейф **по коже** (полоса минус окна, только пиксели кожи, яркость > 95):
все 23 ранее отгруженных рава 3.8–16.5, аккуратный эдит 10.4, перерисовки 22.3 / 46.2 / 76.5.
`SKIN_ACCEPT = 18`. Дрейф по полосе остался в распечатке, но воротами больше не является.

## Почему у арта множитель амплитуды

Плейт в полный рост: межзрачковое расстояние 147 px против эталонных 101, рычаги костей в 1.46
раза длиннее, и те же градусы швыряют макушку на 30.7 px в `idle` и 34.1 px при зажатом тапе
(бюджет — 30). Поймали тесты, не телефон. В манифесте у арта стоит `"motion": 0.8`, он множит
ключи `rotation` (трансляции не трогаются — там абсолютные позиции костей): после него 24.7 /
15.4 / 27.4 / 26.2 px — в одной полосе с остальными ригами.

## Что осталось по костюму

`transparent_s1`, `transparent_s2`, `transparent_s3` — боксы исправлены, кропы нарезаны, генерации
закрытых глаз с этих кропов **отклонены** (22.3 / 46.2 / 76.5 по коже): модель перерисовывала
лицо. Нужны новые генерации с полосой глаз, а не с квадратом лица, плюс `mouth_open` для `talk`.
