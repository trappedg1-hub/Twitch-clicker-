# Приёмка rig_v11 — день 4: `t4_flash`

Кадр «Готово?» перед финалом йоги. В манифесте он стоял как `fallback`: детектор не нашёл базис и
подставил боксы на всё тело, хотя лицо в кадре крупное — глаз 44 px, базис ~95 px, как у `t4_s2`.

## Где тут была развилка

После дня 3 я записал `t4_flash` в «лицо мелкое» по контактному листу — на превью 460 px лицо
выглядело мелким. На кропе с сеткой видно, что это ошибка: глаз 44 px против 49 px у `t6_s0` и
48 px у `t4_s2`, которые уже мигают. Правило простое: масштаб лица читается только по сетке в
нативном разрешении, а не по превью.

Сам патч собрался с первого прохода: 7.19 по коже, 7.53 по полосе, то есть дрейф ровный —
модель закрыла веки и не тронула румянец.
