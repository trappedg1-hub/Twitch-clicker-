# Риг v2 — что смотреть

Третий круг. Жалоба была: «всё равно желе, гостинг при тапе, не живая — просто деформируется».
Причина оказалась не в амплитуде, а в весах: каждая вершина получала долю почти от каждой кости
(падение по высоте σ = 190 px + размытая маска волос). Отсюда и желе, и «призрак» кромки волос.

Теперь вес пикселя — одна часть, часть жёсткая, части сходятся в узких суставах. Гнётся только шея
(56 px) и поясница (30 px), голова с лицом, волосами и наушниками — одно твёрдое тело, ноги на стуле
прибиты к root. Кресло и стол не анимируются вообще.

## Цифры (22 арта, `experiments/audit_rigs.mjs`)

| метрика | было | стало |
| --- | --- | --- |
| сжатие волос в повороте | ×5.3 | ×2.1 |
| сложенных треугольников (гостинг) | 547 | **0** |
| растяжение лица | 0.37 % | 0.05 % |
| спинка кресла | 8.0 px | **0.0 px** |
| тап: голова / грудь | 8.4 / 4.0 px | 9.8 / 1.8 px |

Движение по частям, покой: голова 12.4 px, грудь 5.1 px. Тап: 3.9 / 1.8 px — голова в 2.2 раза
подвижнее груди, поэтому читается кивок, а не «дыхание всем телом».

## Где смотреть в игре

https://twitch-clicker.vercel.app — героиня на сцене, клик по ней = тап, донат = реакция.
Откат на старый риг, если что-то не так: `?rig=0` или `localStorage.mt_rig_off_v1 = '1'`.

Пересобрать всё это:

```bash
bash experiments/render_proof.sh
python3 scripts/rig_deliverable.py compare --a /tmp/renders/before_tap --b /tmp/renders/tap \
  --label-a "БЫЛО · тап" --label-b "СТАЛО · тап" --width 306 --out deliverables/rig_v2/compare_tap.webp
```
