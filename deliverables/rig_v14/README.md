## Дубль, который нашёлся по дороге

`public/art/heroine_t4_flash.webp` и `public/art/heroine_t4_s3.webp` — **один и тот же файл**
(`847444` байт, одинаковый md5), но в манифесте у них были разные боксы глаз: у `t4_flash`
`[[445,293,489,327],[537,275,583,300]]`, у `t4_s3` — на 10–15 px выше и шире. На одинаковых
пикселях это не может быть верно для обоих. Проверка по сетке подтвердила боксы `t4_flash`
(центры глаз `(466,307)` и `(560,287)` против `(466,298)` и `(572,281)`), поэтому `t4_s3`
переведён на тот же набор и его патч пересобран.

Цена была не косметическая: дрейф `t4_s3` по старым боксам показывал **10.83**, по настоящим —
**5.19**. Цифра была честной, просто мерила не тот участок. Блинк `t4_s3` проверен заново.

| заплаты (глаза / рот) | 190×102 / 143×80 | те же |

## Как сделан рот

По целому плейту промпт «open her mouth» **дважды** уходил в content-фильтр. Сработал кроп лица
в нативном разрешении — `400,210,660,440` (260×230, без апскейла, тот же приём, что закрыл веки
`t3_s1`): `align --crop 400,210,660,440` дал **5.28**, масштаб 1.00. То есть для рта годятся оба
пути — целый плейт (848 px) и нативный кроп лица, — а не годится только кроп самого рта.

## Итог по покрытию

`talk` теперь у **25** артов, `mouth_fixed` — 7 (на каноне рот уже открыт), `skip` — 4. В сцене не
осталось арта, где героиня говорит молча: без `talk` только `transparent_s0…s3` — страница
костюма, где реплик нет. Ригов 36 (22.5 МБ), тесты 129/0, `tsc` чисто.
