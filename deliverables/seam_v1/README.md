# Шов головы: измерение (seam_v1)

Остаточный дефект рига — полоса на кромке головы и волос, которая тянется, пока голова
поворачивается, а комната позади стоит. Раньше он был описан словами. Теперь у него есть число,
прибор и охрана в тестах.

## Прибор

`scripts/mesh_smear.mjs` (`npm run qa:smear`) гоняет **все анимации всех 36 ригов** покадрово и
считает для каждого треугольника два числа:

* **сдвиг ребра в пикселях** — насколько вытянулось самое длинное ребро. Это то, что видно;
* **коэффициент площади** — во сколько раз изменилась площадь. Это то, что обманывает: треугольник
  -иголка даёт ×6, не сдвинув ни одного угла (у t1_s0 ровно так: 5.94 и 0.0 px).

Сортировка — по пикселям, потому что смотреть надо на них.

## Что пробовали и почему не пошло

| попытка | шов (t1_s0, `turn`) | что сломала |
|---|---|---|
| адаптивная триангуляция у шва (4×) | 28.5 → **132.2** площади, кадры попиксельно те же | ничего не улучшила: разрыв в весах, а не в сетке |
| расширить полосу головы `HEAD_EDGE` 0.84 → 0.70 | 26.0 → **16.5 px** | макушка теряет вес, `rigLife` ловит «лицо тянется 0.33 %» |
| «юбка»-эллипс вокруг головы (доля 0.60) | **12.0 px** | спинка кресла уезжает на 10.4 px — правило «кресло не двигается» |
| «юбка» по маске волос (доля 0.60) | **23.4 px** | маска обрезана по 1.30 спана и до шва (733, 358) не достаёт |

## Вывод

Одна текстура не может отдать чёткую кромку: кромка принадлежит движущейся части, значит она
обязана тянуться в полосе между «движется» и «стоит». Размазать полосу можно только за счёт
жёсткости лица или неподвижности кресла — оба запрещены.

Чистое решение — **слои**: голова с волосами отдельным спрайтом со своей альфой поверх корпуса.
Разрез по шее и плечам идёт *внутри* её тела, поэтому дырок закрашивать не нужно — под головой
остаются пиксели корпуса. Фон комнаты уже отдельный: у плейтов есть альфа-канал (46.8 %
непрозрачных пикселей на t1_s0 — это её силуэт вместе с креслом), комната рисуется под ними.

## Охрана

`tests/meshSmear.test.ts` — на 7 плейтах, включая худшие: падает, если ребро вытянется больше
32 px (сегодня 28.0) или появится сложенный треугольник. Порог — не цель, а сигнализация: если шов
вырастет вдвое, это станет известно до игрока.

## Как повторить

```
npm run qa:smear                 # таблица по всем 36 ригам
npm run qa:smear -- t1_s0        # один плейт
```
