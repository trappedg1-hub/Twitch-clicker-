# Риг v4 — она смотрит на курсор

Круг 5. Всё, что риг играл до сих пор, было **авторским**: двадцатисекундная петля, которая ничего
не знает о игроке. Именно поэтому даже живая петля остаётся записью человека, а не человеком.
Добавлен один живой канал — указатель.

## Что происходит на экране

| действие игрока | что делает героиня |
| --- | --- |
| ведёт курсор по сцене | поворачивает голову за ним: голова 3.1°, шея 0.9°, корпус 0.3° — цепочка, а не поворот картинки |
| уводит курсор со сцены | медленно возвращается в ноль |
| тапает по ней (телефон) | смотрит в точку нажатия (pointerdown приходит раньше клика), потом кивает |
| ничего не делает | двадцатисекундная петля из v3 идёт своим ходом |

## Почему это читается как живое, а не как поворот картинки

1. **Цепочка делит работу.** Голова берёт весь угол, шея треть, корпус восьмую — те же 30 % / 11 %
   наклонного действия, что и в авторских взглядах петли. Живой взгляд и авторский — один жест.
2. **Отставание.** Не lerp, а пружина: голова доходит до цели на ~0.3 с позже курсора, с лёгким
   перехлёстом (демпфирование 0.82 от критического). Волосы догоняют голову сами — это физика.
3. **Бюджет, а не вкус.** Полное отклонение — 4.3° на макушке, ~23 px на плате: как самый глубокий
   взгляд петли, и тише, чем `turn` (3.35° + 0.95°). Живой канал не имеет права перекрикивать
   собственную игру героини.
4. **Чувствительность в центре.** Курсор мапится кубическим корнем: средняя треть экрана не
   мёртвая, у краёв — плавное насыщение.

## Как это устроено

`src/heroine/gaze.ts` — вся математика без Pixi: пружина `GazeSpring`, маппинг указателя
`aimFromPointer`, разбивка углов `gazeDegrees`, запись в скелет `applyGaze`.

```ts
// LiveHeroine.update, каждый кадр, ПОСЛЕ bone.update(dt):
const gaze = this.gaze.step(dt);
if (!this.gaze.settled) applyGaze(bone.skeleton, gazeDegrees(gaze));
```

Две ловушки, обе проверены тестом и обе стоили времени:

- **Таймлайны OpenBone абсолютные.** Смещение аддитивно только для текущего кадра: следующий
  `bone.update()` заново собирает позу из таймлайнов, поэтому накопления нет.
- **Без `updateWorldTransform()` запись не видна.** Рантайм рисует закэшированные мировые матрицы;
  замер: 0 px против 33 px для 6°. `applyGaze` вызывает его сам.

## Замеры

`tests/rigGaze.test.ts` — 6 тестов, всего в наборе **114**:

- пружина доходит до цели (< 2 %), перехлёст есть, но не звенит (пик < 1.2), NaN не появляется;
- отпускание возвращает в ноль;
- маппинг монотонный, центр чувствительный, вырожденный ввод зажимается;
- полное отклонение двигает макушку на 23.7 px, кресло — **0.00 px**;
- три секунды удержанного взгляда не уползают (дрейф < 30 px);
- риг без кости головы не падает.
