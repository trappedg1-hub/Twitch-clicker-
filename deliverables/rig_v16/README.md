# Приёмка rig_v16 — риги в бинарном формате: 22.5 МБ → 10.8 МБ

## Что в папке

| файл | что показывает |
|---|---|
| `blink_json.png` | раскадровка `blink` из старого набора (JSON-документы) |
| `blink_obonb.png` | та же раскадровка из нового набора (`.obonb`) — попиксельно то же самое |
| `scene_day6_obonb.png` | сцена на дне 6 из настоящего браузера, риг грузится уже из `.obonb` |

## Зачем

23 МБ JSON на 36 артов — это то, что парсится на телефоне при каждой смене платы. OpenBone умеет
бинарный документ, и рантайм отличает его от JSON по первым байтам (`parseDocument`), так что в
игре поменялся только адрес файла.

| | JSON (minified) | `.obonb` |
|---|---|---|
| `t1_s0` | 670 КБ | **319 КБ** |
| все 36 | 22.5 МБ | **10.8 МБ** |
| индекс | 9 КБ | 9 КБ (+ размер каждого документа) |

## Как проверял, что не потерялось

Не «на глаз»: один и тот же кадр прогнан из обоих наборов через реальный рантайм, `rig_preview`
отрисовал раскадровки, они сравнены попиксельно — **max diff 0**. Плюс сквозной прогон в браузере
по всем 6 дням × 5 подстейджам: **26 живых, 4 flat** (те же четыре `skip`), ошибок в консоли нет.

## Что нашлось по дороге

Смена формата обнулила **второй живой баг**, который до этого был замаскирован первым: `talk()`
ставил дедлайн речи раньше, чем проверял, есть ли в документе `idle_talk`. На семи артах без рта
`update()` затем играл несуществующую анимацию — исключение внутри кадра, `fail()`, и риг гас до
перезагрузки. Теперь это две чистые функции в `src/heroine/talkPolicy.ts` под тестом.

## Инструменты

* `node scripts/publish_rigs.mjs` — паблишер (бывший `publish_rigs.py`), пишет `.obonb` + `index.json`
  и убирает устаревшие `.obone`.
* `scripts/rig_doc.mjs` — `readRigDoc(path)` для всех node-инструментов: принимает и `.obonb`, и
  лабораторный `.obone`.
* Лаборатория (`experiments/rig-lab`) по-прежнему хранит pretty-printed JSON — его читают глазами.

Тесты: **134/0**, `tsc` чисто.
