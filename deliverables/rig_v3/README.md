# Риг v3 — двадцатисекундный такт

Круг 4. Круг 3 убрал желе (веса-части), но «не живая» осталось: восемь секунд покоя выглядят
живыми ровно до второго прохода. К этому моменту глаз выучил ритм вдохов и позиции четырёх
морганий — дальше она гифка, а не человек.

Петля `idle` теперь **20 секунд**, и в ней нет ни одного повторяющегося такта.

| что | было (8 с) | стало (20 с) |
| --- | --- | --- |
| вдохи | 2, одинаковая глубина | 5, глубина 2.6–3.4 px, четвёртый — вздох |
| взгляды | дрейф головы на 0.85° | 4 взгляда до 2.0°, третий — туда и обратно («думает») |
| моргания | 5 + одно двойное | 15, интервалы 0.12–2.35 с, два двойных, пять — за 0.1 с до взгляда |
| речь (`idle_talk`) | 2 прохода в первой трети петли | 7 всплесков через 2.8 с на всю петлю |
| шея / корпус | ±0.34° без задержки | 30 % и 11 % от головы с задержкой 0.2 / 0.3 с |
| `turn` | обрыв на −1.8° | антиципация, моргание перед поворотом, возврат в ноль |

## Файлы

| файл | что показывает |
| --- | --- |
| `idle_20s.webp` | покой 20 с в реальном времени: пять вдохов, четыре взгляда, пятнадцать морганий |
| `turn_glance.webp` | реакция `turn` (2.4 с): она оглядывается, веко опускается на 0.09 с, голова возвращается в ноль |
| `storyboard_idle.png` | стоп-кадры по лицу: моргание, взгляд вправо, перехлёст на возврате, взгляд влево, двойное, «думает» |

Сравнение со старым ригом осталось в `deliverables/rig_v2/` (`compare_idle.webp`, `compare_tap.webp`).

## Что мерили

- `npm test` — **108 из 108**. Тест «покой — это дыхание» больше не падает на кромке волос: голова
  и волосы, висящие ниже подбородка, считаются головой (это их анатомия), а тело — то, что ниже
  шейного сустава. Макушка ходит 21.5 px, тело (плечи, грудь, бёдра) — 10.5 px, кресло и пол — 0.00.
- `experiments/audit_rigs.mjs`, 22 арта: folds **0**, растяжение ≤ 2.19, лицо ≤ 0.22 %,
  кресло/пол **0.00 px**.
- Покадровая разница по всей петле (8 fps): средняя 1.34 из 255, минимум 0.105 — нет ни одного
  участка, где картинка замирает: самый тихий отрезок 10–12.5 с (пауза между вдохами).

## Пересобрать

```bash
python3 scripts/build_miya_rig.py --all && python3 scripts/publish_rigs.py
node experiments/dump_frames.mjs t1_s0 idle 20 8 > /tmp/idle.json
python3 scripts/rig_preview.py /tmp/idle.json --crop bust --scale 0.45 --out /tmp/idle --strip 40
python3 scripts/rig_deliverable.py animate --folder /tmp/idle --fps 8 --width 400 --out deliverables/rig_v3/idle_20s.webp
python3 scripts/rig_deliverable.py sheet --label "покой 20 с" --folder /tmp/idle \
  --at 0.4,1.17,2.3,3.6,7.2,9.1,13.0,18.0 --src-fps 8 --out deliverables/rig_v3/storyboard_idle.png
```
