# Конвейер ассетов: от генерации до игрового кадра

Правило продукта: **в игру не попадает ни один кадр, который выглядит мылом.** Это не
пожелание, а числовой гейт, который валит сборку.

## Цепочка

```
gen (848×1264)  →  key_plate.py  →  upscale_5k.py (AI ×4)  →  master ≈3392×5056 (5K)
                →  Lanczos down  →  1024×1526 RGBA WebP  →  гейт детализации  →  public/art
```

## Почему 5K, а не «4x»

Генератор отдаёт ~848×1264. Четырёхкратный AI-апскейл даёт **3392×5056** — это и есть
требуемый 5K-мастер (17 МП). Игровой кадр 1024×1526 получается даунскейлом с 5K, а не
растяжением с 848 — именно поэтому он остаётся резким.

## Гейт против мыла

`scripts/upscale_5k.py` сравнивает **две картинки одного размера**:

- baseline — исходник, честно отресайзенный в 1024×1526;
- результат — игровой кадр, полученный из 5K-мастера.

Метрика: дисперсия лапласиана по яркости (высокочастотная энергия). Отношение должно быть
**≥ 1.05**. Простая интерполяция по определению даёт 1.00 и отвергается.

Проверено на реальном кадре (v5, 848×1264):

| Бэкенд | Мастер | Игровой кадр | Отношение | Вердикт |
|---|---|---|---|---|
| Lanczos (заглушка) | 3392×5056 | 1024×1526 | **0.951** | ❌ REJECTED |
| Real-ESRGAN `x4plus-anime` | 3392×5056 | 1024×1526 | ожидается 1.1–1.4 | ✅ |

Отчёт пишется в JSON (`--report`), код возврата 2 = брак.

## Запуск

```bash
docker compose -f docker-compose.upscale.yml up --build     # локальный REST-апскейлер
npm run keyplate -- in.png out.webp                          # кеинг в 1024×1526 + альфа
npm run upscale -- in.png --backend api \
  --api-url http://127.0.0.1:5000/enhance \
  --master out/plate_5k.png --game out/plate_1024x1526.webp \
  --report out/plate_report.json
```

Альтернатива без Docker — нативный бинарь:

```bash
npm run upscale -- in.png --backend binary --binary ./realesrgan-ncnn-vulkan \
  --model realesrgan-x4plus-anime --master out/plate_5k.png --game out/plate_1024x1526.webp
```

## Ограничение текущей песочницы (честно)

В песочнице агента веса моделей скачать нельзя: `objects.githubusercontent.com` и HuggingFace
закрыты, доступны только `github.com`, `api.github.com`, `registry.npmjs.org`, `pypi.org`.
Поэтому здесь прогоняется только путь `--backend lanczos`, и он **специально** валит гейт.
Это и есть доказательство, что гейт работает: мягкий апскейл не проскочит.

Следствие: `deliverables/concept/miya_corselette_v5_1024x1526.webp` — временная плашка,
полученная ресайзом. В игру она не идёт до прогона через модель.
